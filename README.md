# Portfólio da Stephany

Portfólio profissional desenvolvido para apresentar minha experiência como
Desenvolvedora Fullstack, UI/UX Designer e Analista de Dados.

O projeto reúne informações sobre minha trajetória profissional, formação,
habilidades técnicas e principais projetos em desenvolvimento web, design,
back-end e análise de dados.

## Sobre o projeto

O portfólio foi construído com Nuxt e Vue, com uma interface responsiva
inspirada em um layout editorial. A página apresenta:

- apresentação profissional e formas de contato;
- experiências profissionais;
- formação acadêmica;
- grupos de habilidades e tecnologias;
- projetos com descrição, categoria, status e links;
- navegação entre os projetos em destaque.

## Projetos apresentados

### Will It Rain On My Parade?

Painel com mapa interativo que transforma dados climáticos da NASA POWER API em
informações acessíveis para o planejamento de viagens e atividades. O projeto
envolveu levantamento de requisitos, prototipação no Figma e desenvolvimento
com Next.js e Tailwind CSS.

### HaCARthon – SICAR

Protótipo de aplicativo mobile para apoiar produtores rurais na regularização
de imóveis no Cadastro Ambiental Rural. O projeto inclui mapa interativo,
cadastro de propriedades e demarcação por GPS.

### VibraniumCore-API

API RESTful para gestão de carteira de investimentos, com autenticação JWT,
Prisma e PostgreSQL. A aplicação atualiza preços de ativos em tempo real por
meio da BRAPI e protege a integridade das movimentações registradas.

Repositório: [VibraniumCore-API](https://github.com/olv-stephany/VibraniumCore-API)

### SearchAddress

Pipeline em Python para encontrar endereços a partir de coordenadas geográficas
em massa. Utiliza a malha territorial do IBGE e spatial join com GeoPandas para
associar cada ponto ao município e estado correspondentes.

Repositório: [SearchAddress](https://github.com/olv-stephany/SearchAddress)

## Executando localmente

### Pré-requisitos

- Node.js
- npm

### Instalação

Clone o repositório, acesse a pasta do projeto e instale as dependências:

```bash
git clone https://github.com/olv-stephany/PortfolioFullstack.git
cd PortfolioFullstack
npm install
```

### Servidor de desenvolvimento

Inicie o projeto em modo de desenvolvimento:

```bash
npm run dev
```

Depois, acesse [http://localhost:3000](http://localhost:3000).

### Build de produção

Para gerar a versão de produção:

```bash
npm run build
```

Para visualizar localmente o build gerado:

```bash
npm run preview
```

Também é possível gerar uma versão estática:

```bash
npm run generate
```
